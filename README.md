# Pakistan and Bangladesh Tech Communities Index

A free, public, community maintained index of tech communities for Pakistani and Bangladeshi developers, students and freelancers. WhatsApp, Telegram, Discord, Reddit and Facebook groups.

Want your group listed? Open a pull request. Listing is free forever. Links are community submitted, always check a group before you join.

Last updated: 20 September 2026.

## Pakistan (Urdu and English)

Reddit:

* reddit.com/r/pakistan (about 197K members)
* reddit.com/r/PakistanTechnology
* reddit.com/r/PakistaniTech

Telegram: search these names on TGStat (tgstat.com) for the live invite links, invites rotate often:

* Unseen tech (about 23.5K)
* Tech Zonia
* Defence Squad (about 83K)

Communities:

* Code for Pakistan (civic tech, open source)
* PAFLA, the Pakistan Freelancers Association (find them on Facebook)
* GDG Karachi, GDG Lahore and local AI meetups (find them on Meetup)

## Bangladesh (Bengali and English)

Telegram:

* Programming Hero community: https://t.me/pHeroTG

Reddit:

* reddit.com/r/bangladesh (about 52K members)

Communities:

* DevSonket (developer community)
* Dev Skill (learning and contest platform)
* BdOSN, the Bangladesh Open Source Network
* bdapps developer groups (official, regional)
* Tech Bangladesh network (WhatsApp groups, find links via their Facebook page)
* GDG Dhaka and local AI meetups (find them on Meetup)

## How to add your group

Open a pull request that adds one line per group:

* name, platform, invite link, language, who it is for

Maintainers review within days. No spam, no paid listings.

JustBot is free to start: https://justbot.co/?v=2
